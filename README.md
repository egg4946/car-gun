# ドライブバイ・ガンナー (car-gun)

**運転か、射撃か。**
ハンドルを離している間だけ銃を撃てる、ブラウザで遊ぶ 3D カーアクションゲームです。
ただしハンドルを離すと車は勝手に曲がり続けます。敵を撃つか、ハンドルを握って立て直すか。その二択がこのゲームの核です。

- three.js + Vite の素の JavaScript。画像・モデル・音声ファイルは使わず、すべてコードで生成しています。
- インストール不要。ブラウザだけで遊べます。

## 遊び方

```bash
npm install
npm run dev
```

ブラウザで <http://localhost:5173> を開き、START を押します。タイトル画面でマップ(市街地 / 森の林道)を選べます。

### 操作

| キー | 動作 |
|---|---|
| W / S | アクセル / ブレーキ(止まって S を押し続けるとバック) |
| A / D | ハンドル |
| Shift | サイドブレーキ(ドリフトのきっかけ) |
| **Space 長押し** | **ハンドルを離す(この間だけ撃てる)** |
| マウス / クリック | 照準 / 射撃 |
| 右クリック長押し | 集中(スローモーション) |
| C | 視点切替(運転席 / 後ろから) |
| M | ミュート |

## ゲームの仕組み

- **運転か射撃か**: 撃てるのはハンドルを離している間だけ。弾の補充はハンドルを握っている間だけ進みます。速く走るほど・ドリフトするほど弾はばらけます。
- **敵の弾は運転でよける**: 敵は赤いレーザーで狙ってから撃ってきます。速く走っていれば当たりにくくなります。
- **敵**: 歩兵(撃つ・轢く)、ドローン、追跡車(同じ車の物理で体当たりしてくる)。
- **手配度★0〜5**: 暴れるほど上がり、敵が増えます。★4 で装甲トラック、★5 で武装ヘリ(予告つきのミサイル)が現れます。
- **街を壊せる**: 街灯・信号・木・自販機・消火栓・ガラス・一般車などはなぎ倒したり撃ったりして壊せます(おまけ点)。ドラム缶と駐車車両は爆発して周りの敵を巻き込みます。
- **スタイル得点**: ドリフト中・ノールック・手放し3秒・高速・遠距離・巻き込みで倒すと倍率アップ。3 秒以内に倒し続けるとコンボ。
- **集中ゲージ**: ドリフトと撃破で溜まり、右クリック長押しで時間がゆっくりになります。
- **アイテム**: 道路の光の柱。リペア / ニトロ / 無限弾。
- **時間**: 1 ラウンド 90 秒。倒すと時間が延びます(ボスは大きく延びる)。
- **リザルト**: 称号(「ハンドルいらない人」「街の破壊神」など)と記録を表示し、X(Twitter)で共有できます。

## 開発

```bash
npm test         # node:test でロジックのテスト
npm run build    # dist/ に本番用ビルド
npm run preview  # ビルド結果の確認
```

### 構成

| ファイル | 役割 |
|---|---|
| `src/main.js` | エントリ。入力・ゲーム状態・HUD・メインループ |
| `src/vehicle.js` | 車両物理(タイヤの横力・ドリフト・衝突)。three.js 非依存 |
| `src/car.js` | プレイヤー車の見た目・カメラ・揺れ |
| `src/world.js` / `src/cityBlock.js` / `src/cityTextures.js` | 市街地マップ(無限生成) |
| `src/forest.js` | 森の林道マップ |
| `src/enemies.js` / `src/ai.js` | 敵の出現・思考(射撃・追跡・ボス) |
| `src/props.js` / `src/destructibles.js` | 壊せる小物と、破片・炎・爆発の演出 |
| `src/weapon.js` | 銃(連射・補充・ばらつき) |
| `src/style.js` / `src/wanted.js` / `src/focus.js` | スタイル得点と称号 / 手配度 / 集中ゲージ |
| `src/traffic.js` / `src/pickups.js` / `src/pickupView.js` | 一般車 / アイテム |
| `src/audio.js` / `src/effects.js` | 効果音・BGM(Web Audio で合成)/ タイヤ痕・煙 |
| `tests/` | `node:test` のテスト |

ゲームのロジック(物理・AI・得点など)は three.js に依存しない純粋なモジュールに分けてあり、`npm test` で Node 上でテストできます。
